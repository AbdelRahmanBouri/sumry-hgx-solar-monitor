FORECAST

Solar output estimate

Set this installation's GPS location and array details to model expected output — combining sun position for your coordinates with live cloud-cover data. The result drives the Solar potential page, which compares modelled potential against what the inverter actually captured. A [site] table in the config file seeds these fields on start; edits made here take precedence from then on.

Array capacity is the panels' combined nameplate — the number of modules times each module's rated watts — not the most the inverter's solar charger can accept. Leave it at the nameplate. The level of the potential line is not set here: it is learned from the array's own output over the last week, by sun height, using only readings taken while the battery could still accept charge. The fallback efficiency applies until enough of those readings exist, and 0.75–0.85 is the credible range for it.

Tilt and azimuth describe how the panels face: 0° tilt is flat, 180° azimuth is due south. A dual-slope array is split evenly across both faces of a pitched roof, so half the modules face the opposite way from the azimuth given here. Because the two faces cancel, a split array collects within 1–2% of a flat one whatever the pitch. The string layout only affects the recoverable-loss comparison on the potential page; the live line learns whatever the wiring costs from the readings themselves. Clear tilt and azimuth to fall back to a flat-plane model.

Weather comes from Open-Meteo and needs internet access; without it the estimate falls back to clear-sky only and the dashboard says so. Bear in mind that a full battery with light load makes the inverter throttle production, so measured output can legitimately fall below a correct estimate.
